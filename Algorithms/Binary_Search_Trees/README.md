# Binary Search Trees

BST-specific invariants: ordered traversal, validation, search/insert/delete.

## Classic problems to practice
- Validate Binary Search Tree
- Kth Smallest Element in a BST
- Lowest Common Ancestor of a BST
- Insert into a Binary Search Tree
- Convert Sorted Array to Binary Search Tree

## How to use this folder
- One `.py` file per problem, named after the problem (e.g. `two_sum.py`).
- Start from `template.py` for a consistent Solution + test scaffold.
- Note the time/space complexity in a comment at the top of each solution.
