# Sliding Window

Maintain a variable-size window over an array/string to track a running property.

## Classic problems to practice
- Longest Substring Without Repeating Characters
- Minimum Window Substring
- Longest Repeating Character Replacement
- Sliding Window Maximum
- Permutation in String

## How to use this folder
- One `.py` file per problem, named after the problem (e.g. `two_sum.py`).
- Start from `template.py` for a consistent Solution + test scaffold.
- Note the time/space complexity in a comment at the top of each solution.
