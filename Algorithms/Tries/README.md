# Tries

Prefix trees for word storage/lookup: autocomplete, prefix search, word search.

## Classic problems to practice
- Implement Trie (Prefix Tree)
- Word Search II
- Design Add and Search Words Data Structure
- Longest Word in Dictionary
- Replace Words

## How to use this folder
- One `.py` file per problem, named after the problem (e.g. `two_sum.py`).
- Start from `template.py` for a consistent Solution + test scaffold.
- Note the time/space complexity in a comment at the top of each solution.
